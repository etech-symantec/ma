법인명 / 국가 / 위치 / 점검 방식 / 구성방식 / 상위 법인(부모) / 담당 엔지니어 / 고객사 담당자 / 비고는 이 법인(그룹)에 속한 모든 자산 항목에 공통으로 적용됩니다. Support ID와 구축 엔지니어는 이 법인에 Support ID가 하나뿐일 때만 여기서 함께 수정할 수 있습니다. 구축 일자를 수정하거나 Support ID가 여러 개인 경우는 각 Support ID 영역의 ✎ 버튼에서 따로 수정합니다.

다른 법인을 상위(부모)로 지정하면, 두 법인은 부모-자식 관계로 연결됩니다. 이렇게 연결된 법인들은 법인 정보 영역에 서로의 Support ID를 모두 함께 보여줍니다 (예: 같은 그룹사의 여러 법인이 Support ID를 나눠 쓰는 경우). 관계가 없는 법인은 기존처럼 표시됩니다.
